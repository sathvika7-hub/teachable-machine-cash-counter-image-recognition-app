# teachable-machine-cash-counter-image-recognition-app
AI cash counting app built with Google Teachable Machine. Uses image recognition to detect currency notes via camera, identifies denominations, counts them and calculates total amount instantly. Workflow: dataset collection, model training, app integration &amp; real-time cash counting.
